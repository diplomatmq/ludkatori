# Telegram Бот для отслеживания игрового автомата 🎰

Этот бот отслеживает стикер игрового автомата (🎰) в Telegram и сообщает о результатах.

Бот написан на **aiogram 3.x** - современной асинхронной библиотеке для Telegram Bot API.

## Особенности

✅ Админ-панель для владельца бота
✅ Настройка победной комбинации
✅ Выбор готовых комбинаций (777, BAR, виноград, лимон)
✅ Создание кастомной комбинации
✅ **Временные события с конкурсами**
✅ **Два типа событий:**
  - 🎯 "Первый кто выбьет N раз" - первый достигший цели побеждает
  - 🔥 "Подряд N раз" - нужно выбить комбинацию N раз подряд
✅ **База данных для отслеживания прогресса**
✅ **Таблица лидеров**
✅ **Автоматический подсчёт серий** (с сбросом при промахе)
✅ **Система подарков:**
  - 🎁 Уникальные подарки из коллекции Telegram
  - 🔄 Автоматический выбор случайного неиспользованного подарка
  - 📝 Отслеживание выданных подарков (не повторяются)
  - 📥 Загрузка подарков из файла или добавление вручную
✅ **Кастомные эмодзи** в сообщениях о победе
✅ Бот молчит на проигрыши, отвечает только на победу
✅ Сохранение настроек в файл

## Установка

1. Установи Python 3.8 или выше

2. Установи зависимости:
```bash
pip install -r requirements.txt
```

## Настройка

1. Создай бота через [@BotFather](https://t.me/botfather) в Telegram:
   - Отправь команду `/newbot`
   - Придумай имя и username для бота
   - Получи токен бота

2. Создай файл `.env` (скопируй `.env.example`):
```bash
copy .env.example .env
```

3. Открой файл `.env` и вставь свой токен, admin ID и ID чата:
```env
BOT_TOKEN=123456789:ABCdefGHIjklMNOpqrsTUVwxyz
ADMIN_ID=793216884
ALLOWED_CHAT_ID=-1002345678901
```

### Как узнать ID чата:

**Способ 1 (через бота):**
1. Добавь бота в нужный чат (группу/канал)
2. Отправь в чат любое сообщение или игровой автомат 🎰
3. В логах бота (в консоли) появится строка: `"Получен игровой автомат... в чате -1002345678901"`
4. Скопируй это число (с минусом!) в `.env` как `ALLOWED_CHAT_ID`

**Способ 2 (через специальный бот):**
1. Добавь [@getmyid_bot](https://t.me/getmyid_bot) в свой чат
2. ID чата будет показан в сообщении

**Важно:**
- ID чата для групп/каналов начинается с минуса: `-1002345678901`
- 🎰 **Игровой автомат** работает ТОЛЬКО в указанном чате
- 🔧 **Админ-панель** (`/start`, `/admin`, `/gifts`) работает в личных сообщениях с ботом
- В личке с ботом игровой автомат НЕ обрабатывается, только команды

## Использование

### Для обычных пользователей:
1. Найди бота в Telegram и запусти командой `/start`
2. Отправь боту игровой автомат 🎰
3. Если выпала победная комбинация - бот ответит

### Для владельца (ADMIN_ID):
1. Запусти бота командой `/start` или `/admin`
2. Увидишь админ-панель с кнопками:
   - **🎰 Выбрать победную комбинацию** - настроить основную победную комбинацию
   - **🎉 Создать событие** - запустить временный конкурс
   - **📊 Текущее событие** - статистика и таблица лидеров
   - **🛑 Остановить событие** - завершить текущий конкурс
   - **ℹ️ Текущие настройки** - посмотреть текущую победную комбинацию

#### Создание события:
1. Нажми **🎉 Создать событие**
2. Выбери тип:
   - **🎯 Первый кто выбьет N раз** - побеждает первый, кто наберет нужное количество
   - **🔥 Подряд N раз** - нужно выбить комбинацию N раз подряд (промах сбрасывает счётчик)
3. Выбери целевую комбинацию (777, BAR, виноград, лимон или кастомная)
4. Выбери сколько раз нужно выбить (3, 5, 10, 20, 50)
5. Событие запущено! Бот автоматически отслеживает прогресс всех участников

## Управление подарками

### Добавление подарков:

**Через файл:**
1. Создай файл `gifts.txt` со списком URL подарков
2. `/admin` → `🎁 Управление подарками` → `📥 Загрузить из файла`

**Вручную:**
1. `/admin` → `🎁 Управление подарками` → `➕ Добавить вручную`
2. Отправь URL: `https://t.me/nft/GiftName-123456`

**Формат URL:**
- Коллекция: [t.me/emperort1me/c/2](https://t.me/emperort1me/c/2)
- Пример подарка: `https://t.me/nft/LunarSnake-182713`

### Как работает:
- При победе бот выбирает случайный неиспользованный подарок
- Каждый подарок выдаётся только один раз
- В событиях подарок показывается только при финальной победе
- При обычной победе (вне события) подарок показывается сразу

Подробнее: [GIFTS_GUIDE.md](GIFTS_GUIDE.md)

## Технические детали

Игровой автомат в Telegram возвращает значения от 1 до 64. Бот использует **полную таблицу соответствия всех 64 комбинаций**:

Примеры комбинаций:
- **1** = 🎰 🎰 🎰 (BAR BAR BAR)
- **22** = 🍇 🍇 🍇 (виноград виноград виноград)
- **43** = 🍋 🍋 🍋 (лимон лимон лимон)
- **64** = 7️⃣ 7️⃣ 7️⃣ (777)

Кастомные комбинации работают на основе точного соответствия символов и их позиций, которые преобразуются в конкретное значение dice (1-64).

Источник таблицы соответствий: [GitHub Gist](https://gist.github.com/SevaShpun/8cff6d045caa1c763935510eaac23df6)

- **FSM (Finite State Machine)** - машина состояний для многошаговых диалогов
- **SQLite3** - встроенная база данных для хранения событий и прогресса

## Примеры использования событий

### Пример 1: "Первый кто выбьет 5 раз"
1. Админ создаёт событие: тип "Первый кто выбьет", комбинация 777, количество 5
2. Пользователь А выбивает 777 → прогресс 1/5
3. Пользователь Б выбивает 777 → прогресс 1/5
4. Пользователь А выбивает 777 еще 4 раза → **побеждает!**
5. Событие автоматически завершается

### Пример 2: "Подряд 3 раза"
1. Админ создаёт событие: тип "Подряд", комбинация BAR, количество 3
2. Пользователь выбивает BAR → серия 1/3
3. Пользователь выбивает BAR → серия 2/3
4. Пользователь выбивает 🍋 → **серия сброшена** (0/3)
5. Пользователь выбивает BAR → серия 1/3 (начинается заново)
6. Пользователь выбивает BAR → серия 2/3
7. Пользователь выбивает BAR → **побеждает!** (серия 3/3)
